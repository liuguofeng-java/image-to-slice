完整迁移尚未完成。当前是可运行的第一阶段，不是整个项目已经转换为 Vue/TS。

## 已接入现有页面

- Vue 3、Pinia、Vite Vue 插件和 TypeScript 5.9；UI、构建配置、Vue 测试分别进行严格类型检查。
- 资产列表的父子缩进、文字缩略图、菜单、显隐、设置、删除、选择和拖拽由 Vue 组件渲染与处理。
- 列表状态由 Pinia 管理，旧业务流程通过明确的类型化快照和事件边界连接组件；旧列表字符串渲染及事件绑定已删除。
- 并发 AI 控制器由类型化任务注册表管理，不进入可持久化状态；旧任务完成不得移除重试任务，离开页面会取消活动任务。
- 组件卸载会释放指针事件。列表只更新响应式状态，不再直接写入进度标签的 DOM。
- Vue 组件打包后内联到现有 Figma 单文件 HTML，第三方依赖不从 CDN 加载。

## 当前命令与注意事项

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run dev
```

- `dev` 和 `start` 当前仍启动既有 API 与浏览器预览，**尚不是完整 Vue 源码热更新模式**。修改 Vue 组件后运行 `npm run build:ui` 并刷新页面。
- `build:ui` 先构建 Vue 组件，再内联为 `dist/ui.html`；不要直接运行 HTML 拼接脚本。
- 当前 `preview` 仍为原有开发预览，待根入口迁移完成再切换语义，避免在中途指向不存在的生产入口。
- 后端未迁移，修改后端代码仍需重启服务。Figma UI 构建更新后需重新打开插件。
- 按现有 `.nvmrc` 使用 Node 22.22.2；Node 23 不在新增 Vitest 的支持范围内。
- `test:e2e` 的 API 请求全部拦截，使用内存图片，不读取或修改真实草稿，也不调用 AI 模型。截图保存到忽略跟踪的 `test-results/vue-migration/`。
- 保留原来的 Node 单元测试；新增 Vue 组件与状态行为测试使用 Vitest。现阶段还未迁移的源码字符串测试继续保留覆盖。
