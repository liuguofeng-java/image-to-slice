# 参考与实现对照

参考：2026-09-12 用户已登录的 studio.vberai.com/editor。仅查看页面，不下载站点业务代码或接入私有接口。

| 参考区域                | 状态/行为                          | Slice Studio 实现                                     |
| ----------------------- | ---------------------------------- | ----------------------------------------------------- |
| 黑色点阵、双轴标尺      | 平移、缩放、选框尺寸               | Konva 世界坐标与 DOM 标尺                             |
| 顶部浮动条              | 名称、缩放、导入、导出             | 保留紧凑布局；自有 S 标识                             |
| 左侧浮动面板            | 场景、搜索、图层、绿色选中态       | 平面图片层、排序、显隐、锁定                          |
| 右侧属性                | 名称、对齐、X/Y、W/H、旋转、透明度 | Element Plus 深色参数控件                             |
| 底部工具条              | 选择、手形、AI                     | 仅显示真实实现的工具                                  |
| AI 入口                 | 框选、处理、结果                   | 本产品独立的识别/候选确认流程，不宣称复制原站隐藏算法 |
| 窄屏                    | 面板收起                           | 互斥左右抽屉、焦点返回                                |
| 会员/协作/插件/引擎导出 | 不在范围内                         | 完全省略                                              |

正文 Segoe UI / Microsoft YaHei，参数 12px，标题 13px，辅助 11px；不引入远程字体。
