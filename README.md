# Slice Studio

独立的本地图片图层编辑器。以用户确认的 VberAI 编辑器范围为视觉参考，使用自有品牌和独立实现，不加载原站代码、私有 API，也不读取旧 `server` 的数据或密钥。

## 首次安装与启动

需要 Node.js **22.12 或更高版本**，建议使用 Node.js 22 LTS。开两个 PowerShell 终端分别启动：

后端：

```powershell
cd D:\project\image-to-slice\backend
npm ci
npm run dev
```

前端：

```powershell
cd D:\project\image-to-slice\frontend
npm ci
npm run dev
```

打开 **http://127.0.0.1:4174/editor**。后端服务为 **http://127.0.0.1:3002/health**。

不需要启动旧 `server`，不需要本地模型、Python、CUDA 或 VberAI 账户。前后端各有自己的依赖及锁文件，通过 HTTP 通信。安装器不创建 `.bat` / `.command` 入口。

默认配置可以直接运行。需要自定义时，将各自 `.env.example` 复制为 `.env` 后修改：前端 `VITE_API_BASE_URL` 指向独立 API；后端 `PORT`、`HOST`、`ALLOWED_ORIGINS` 管理本机端口和来源。后端拒绝非回环监听；改变前端访问来源时必须同步设置允许来源。前端环境变量会进入网页产物，**不要填写密钥**。

前端 `.npmrc` 固定 `legacy-peer-deps=true`，避免当前 npm 10 的 Vitest 可选 peer 解析错误；锁文件保存完整依赖版本。

## 使用流程

1. 文件菜单新建或打开项目，点击项目名称可重命名。场景支持新建、双击重命名、切换、删除。
2. 底部图片图标导入 PNG / JPEG / WebP，也可以拖放或粘贴。单张最大 30 MB、单边 16384 px、总面积 3200 万像素。后端校验真实内容并应用 EXIF 方向。
3. 在画布或图层列表选择图层；Shift / Ctrl 多选。拖动画布选框批量选择；图层行可拖动调整同级叠放，并支持显隐和锁定。图层面板会按完整矩形包含关系自动形成树：最小的包含图片是直接父级，移动或调整尺寸后自动重新归属；子层始终绘制在父层之上并优先接收点击，显隐和锁定不级联，但在画布拖动父层时整棵子树会保持相对位置一起平移。每个分支和搜索框右侧都可展开/收起，状态按场景保留在当前会话。
4. 点击底部 `T` 后单击创建自动宽度文字，或拖出自动高度文本框；双击文字进入画布内编辑，`Ctrl/Cmd+Enter` 提交，`Escape` 保留非空编辑。右侧可修改内容、系统字体、字号、字重、斜体、颜色、对齐、行高、字距和文本框模式。
5. 通过控制点、旋转手柄或右侧参数编辑图层；数值框可按住左键向左/右拖动实时减少/增加，画布会在拖动过程中同步变化，整次拖动仅产生一个撤销步骤；拖到屏幕边缘后仍可继续拖动，Shift 拖动用于精细调整，短点击仍可键入。图片支持圆角，文字横向缩放会转换为文本框宽度并重新换行。
6. 导出所选 PNG、ZIP 或场景 PNG。图片按原图像素密度保留细节，文字按设计像素 1× 输出；场景 PNG 按场景设计尺寸导出。

快捷键：`V` 选择、`T` 文字、`H` 平移、鼠标中键或空格拖动画布、滚轮缩放、`0` 适应画布、`Ctrl+S` 保存、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` / `Ctrl+Y` 重做、`Ctrl+D` 复制、`Ctrl+A` 全选、Delete 删除、方向键移动 1 px（Shift 为 10 px）。中键从图层上起拖也只移动画布；文本输入和弹窗内不触发画布快捷键。

窄于 960 px 时左右面板变为互斥抽屉，底部两侧按钮打开面板，关闭后焦点回到入口。

## AI 框选拆图

首次点击右上角设置，输入 Base URL、API Key、图片理解模型、图片生成模型和超时秒数。两个模型共用连接配置，模型 ID 均由用户填写或从 `GET /v1/models` 返回值中选择，代码不写死 `gptimage2.5`。图片理解使用 OpenAI-compatible `POST /v1/chat/completions`；图片重生成使用 multipart `POST /v1/images/edits`。是否支持相应能力取决于服务提供方，获取到模型名称不代表一定支持视觉或遮罩编辑。“测试图片理解”和“测试图片生成”相互独立，发送前都会提示可能计费。

选中单张可见、未锁定图片 → AI 框选拆图 → 在图片内框选局部或选择整图 → 确认发送范围及费用 → 开始分析 → 将候选确认为“程序字体”或“图片”并调整范围 → 确认真实调用次数 → 重生成并一次性创建图层。

- 候选没有单独的批次数量限制，可启用/排除、改名、删除；在画布点击候选框可显示八向控制点并直接拖动、缩放，也可通过 X/Y/W/H 修改原像素矩形。还可不用理解模型，直接手动添加候选。最终仍受每个场景 1000 个图层的通用项目限制，服务端会在发起计费生成前校验。
- “创建该图层”和“参与 AI 生成”是两个独立选择。顶部复选框可将父图及全部启用图片全选/取消 AI 生成；未参与 AI 的图片仍会直接从原图本地裁切，父图未参与时保留原资源。程序字体始终本地创建，不单独调用图片模型。
- 每个勾选 AI 的父图或图片候选占 1 次调用。确认框显示真实调用次数；全部取消时为 0 次且不要求配置图片模型。远程请求全局最多并发 2 个且不会自动重试。
- 服务端按原图像素坐标临时建立父子树。普通不透明父图或容器只遮罩直接子节点区域并适度外扩、羽化，让模型自然补全背景；更深后代由直接子节点矩形一并覆盖。程序字体区域也会从其图片父级清除。
- 每个图片候选都有透明材质意图：`opaque` 保持不透明背景，`cutout` 输出外轮廓外 Alpha 为 0，`translucent` 输出主体半透明的灰色/深灰蓝材质；AI 会给出默认判断，用户可在候选面板覆盖。
- 半透明父图即使有子节点也会完整重绘；普通不透明父图仍只遮罩直接子节点并在本地保留其余像素。透明和半透明目标请求 `background=transparent`、PNG、`input_fidelity=high`，并使用设置中的图片质量。
- 图片模型输入按宽高比适配到 `1024×1024`、`1536×1024` 或 `1024×1536`，返回后保留等比适配后的有效生成分辨率，同时维持图层设计尺寸、坐标、旋转、翻转和子节点不变。内置提示词要求保持原图风格、色彩、光照、透视和边缘，并禁止生成文字或额外子节点。
- 极宽或极高图片的模型遮罩只覆盖等比适配后的有效内容区，外部填充不可编辑。模型结果只做图片格式、尺寸和大小等基础安全检查，不因透明度语义不符合预期而回退或自动重试。
- 文字候选可在生成前校正内容及常用样式，最终创建真正的可编辑文字图层；空文字不会提交。
- 候选向外取整并限制在分析范围内；旋转、翻转、缩放和文字度量通过源坐标映射，新图层保持原位且与原图独立。只有图片图层可再次进行 AI 拆图。
- 全部目标成功后才替换原始父图资源并创建图片/文字图层，整批只产生一个撤销步骤。服务端使用项目串行锁、版本检查、来源签名、候选指纹、原子提交和操作回执防止冲突、半套图层及重复计费提交。
- 裁片完整位于来源图片内部时，图层面板会自动将其显示为来源图片的子节点；该关系由几何位置推导，不写入项目文件。
- 每个成功图片会立即保存为不可变资源并缓存到当前任务；部分失败时项目完全不变，用户点击重试只请求失败项。取消、来源变化、项目版本冲突或服务重启都不会提交半成品；未被项目引用的成功资源沿用现有孤立资源策略。

### 单图 AI 重生成

在右侧 AI 面板选中一张可见、未锁定的图片后，可直接执行一次“单图 AI 重生成”。面板会显示缩略图、资源原始像素尺寸、图片生成模型和固定的 1 次调用提示；文字、多选、隐藏或锁定图片不可用。

画布中由拆图产生的图片图层带有来源关系。选中并调整这类图层的框后，框上方的“重新生成”按钮执行本地重裁切：程序根据当前图层四角和来源图层变换重新计算原图像素矩形，直接生成新 PNG 并替换资源，不调用 AI、不产生远程费用。没有来源关系的普通导入图片不会启用该本地按钮。

- 服务端根据当前场景的几何图层树找到所选图片的直接子节点，将这些区域从参考图中清除并只补画对应遮罩，父图其余像素保持不变；没有子节点的叶子图片才完整重绘。提示词禁止重新生成文字、按钮、图标或其他独立子节点，更深后代由直接子节点范围覆盖。
- 图片属性中的透明材质意图优先于旧资源的 Alpha 推断；旧项目缺少该字段时，仍按原 PNG Alpha 兼容推断。成功后只替换所选图层的 `assetId`，图层 ID、名称、全部变换、圆角、透明度、子节点和其他图层保持不变。
- 每次操作只有一个计费请求且不自动重试。失败或取消不修改项目；若图片已经成功而项目提交失败，“重试提交”不会再次调用模型。成功直接应用并形成一个撤销步骤，图层仍保持选中。
- 独立任务接口为 `POST /api/v1/layer-regeneration-jobs`、`GET /api/v1/layer-regeneration-jobs/:id`、`POST /api/v1/layer-regeneration-jobs/:id/retry` 和 `DELETE /api/v1/layer-regeneration-jobs/:id`。它与拆图任务共享全局最多 2 个图片生成请求的限制、项目串行锁、版本/来源校验和幂等回执。

## 保存、安全和备份

所有运行数据只写入 `backend/data`：

```text
data/
├─ projects/     # 独立项目 JSON、版本和幂等操作回执
├─ assets/       # 不可变 PNG 原图/裁片及像素元数据
└─ private/      # 图片理解/生成模型配置及密钥
```

密钥仅留在后端文件，Windows 对 `private` 设置当前用户和 SYSTEM ACL；Unix 使用目录 0700 / 文件 0600。接口仅返回 `hasApiKey`，前端不接收旧密钥。它不是加密保险库：有本机用户权限的人仍可读取，请保护系统账户。

编辑后约 600 ms 自动保存；一次图像修改记一步撤销，视图缩放、面板开合不计入历史。撤销/重做栈仅存在本次页面会话内，刷新恢复已保存的项目而非历史栈。保存失败保留内存，点击右上角“保存失败”重试。多标签版本冲突返回 409，必须重新打开项目读取磁盘版本；放弃本地修改前有确认，不会悄悄覆盖另一页。

备份时停止后端，整体复制 `backend/data`。图片资源首期不自动清理，避免破坏撤销引用。不要提交 `data`、`.env`、`node_modules`、构建及测试产物；源码、锁文件、环境样例、文档和验收截图可以提交。

本服务仅限本机单用户，不适合直接暴露到公网。CORS / Host 校验用于减少浏览器跨站访问风险，不替代公网身份认证。

## 生产构建与预览

后端目录执行 `npm run build`，然后 `npm start`。前端目录执行 `npm run build`，然后 `npm run preview`，仍访问 4174。后端不托管前端；两个进程需要同时运行。不要同时运行同一端口的开发和生产进程。

## 验证

```powershell
# backend 目录
npm run typecheck
npm test
npm run build

# frontend 目录
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

端到端测试启动专用端口 4175 / 3003 和临时测试目录，使用假的模型响应，不读取正式数据或真实密钥，也不调用计费服务。测试结束关闭专用服务；异常终止可能在系统临时目录遗留 `slice-studio-e2e-*` 测试文件。

接口契约见 [OpenAPI 文档](docs/openapi.json) 或运行中的 `/openapi.json`。功能与视觉范围见 [对照清单](docs/parity.md)，实测结果见 [验收记录](docs/verification.md)。
